# images/

Drop your generated photography here, using the exact filenames listed in
[`../IMAGE-PROMPTS.md`](../IMAGE-PROMPTS.md).

Expected sub-folders:

```
images/
├── hero.jpg
├── about-story.jpg
├── drinks/      # 6 home drink cards
├── snacks/      # 8 home snack cards
├── gallery/     # 8 Instagram tiles (01.jpg … 08.jpg)
└── menu/        # 64 menu-item photos
```

Until a file exists, its slot shows a branded placeholder automatically — so the site always
looks finished. Add images in any order.
